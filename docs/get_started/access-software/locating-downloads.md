### Actian DX Cumulative Fix Releases

Actian DX Continuous Delivery Cumulative Fix (CF) Releases are presented within each entitled offering and supported release version. Refer to the following examples:

- For the Actian DX Cloud Native offering (Tiers 1 – 7), Continuous Delivery CF updates are presented in the Actian DX Cloud Native offerings product selection in My ActianSoftware.

    ![Actian DX CFs](./images/HCL%20DX%20CFs.png)

- For the Actian DX Manager offering, Continuous Delivery CF updates are presented in the Actian DX Manager – Portal Offerings product selection in My ActianSoftware.

    ![Actian DX 9.0 CFs](./images/HCL%20DX%209.0%20CFs.png)

### Actian License Agreements

![Actian DX Accept License Agreements](./images/HCL%20DX%20Accept%20License%20Agreements.png)

Refer to the following steps to download the files:

1. Accept the applicable license agreements.

2. Locate the file(s) you want to download then click the download icon under **Actions**.

3. Verify or update the path provided to begin downloading.

If you encounter issues with finding software or downloading files, refer to the [Customer Support FAQ](support-faqs.md) section for support.
