# Getting Started with Actian Digital Experience

In this Getting Started with Actian Digital Experience section, you get an introduction to Actian Digital Experience. This provides an [Actian Digital Experience overview](./product_overview/index.md) where you learn the market trends, what, why, and how Actian Digital Experience is the right solution. You can also see DX in Action with a few recorded demos and learn how to run these demos yourself using a sandbox for Actian Digital Experience Solution Modules Business Solution that runs on Actian SoFy (Actian Solutions Factory). For more information, see [DX Introduction course](https://hclsw.co/hdx-intro). For specific lessons, access the following links:

- [Actian Digital Experience Overview](https://hclsoftwareu.actian.com/component/axs/?view=sso_config&id=3&forward=https%3A%2F%2Fhclsoftwareu.actian.com%2Fcourses%2Flesson%2F%3Fid%3D273): In this lesson, you get an overview on the Actian DX and find many useful links.

- [Actian Digital Experience in Action](https://hclsoftwareu.actian.com/component/axs/?view=sso_config&id=3&forward=https%3A%2F%2Fhclsoftwareu.actian.com%2Fcourses%2Flesson%2F%3Fid%3D279): In this lesson, you see the different recorded demos with DX in action.

- [Try Actian Digital Experience Now](https://hclsoftwareu.actian.com/component/axs/?view=sso_config&id=3&forward=https%3A%2F%2Fhclsoftwareu.actian.com%2Fcourses%2Flesson%2F%3Fid%3D280): In this lesson, you learn how to deploy Actian DX Solution Modules on Actian SoFy and run the previous demos on your own sandbox.
