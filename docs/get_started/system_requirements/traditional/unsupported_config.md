# Unsupported configurations

An "unsupported configuration” is a combination of Actian Software and other dependent products (usually at a specified version, release, fix, or specification level) that is known to not work with Actian Digital Experience and is therefore not supported.

Actian does not provide support for unsupported configurations. Resolutions to deficiencies or incompatibilities found in unsupported configurations are not generally available.

For more details, see the [Actian DX support statement](../../../get_started/software_support.md).
